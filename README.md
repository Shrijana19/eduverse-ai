EduVerse AI Teacher

Learn. Visualize. Interact.

EduVerse AI Teacher is an AI-powered interactive learning platform designed to make complex concepts easier to understand through AI teaching, immersive 3D visualization, and educational videos.
Instead of passive learning, EduVerse helps students see, explore, and understand concepts interactively.

 Features
1) AI Teacher — Interactive, student-friendly concept explanations
2) 3D Learning Environment — Visualize concepts in an immersive classroom
3) Teaching Videos — Engaging visual explanations
4) Visual Learning — Understand concepts through interaction
5) Student-Centric Design — Simple and engaging learning experience

Tech Stack
- React + TypeScript
- Vite
- Node.js
- AI-powered learning
- 3D/Web visualization
- Manus — AI-assisted development
- GitHub

Getting Started
git clone https://github.com/Shrijana19/eduverse-ai.git
cd eduverse-ai
pnpm install
pnpm dev

Problem
Many concepts are difficult to understand through textbooks and static lectures alone.
EduVerse bridges this gap by combining AI, 3D visualization, and interactive educational content to turn passive learning into an experience.
